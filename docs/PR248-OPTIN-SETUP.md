# Online setup

A fresh installation without online configuration starts offline. In Settings, open Online, choose re-psn, enter your server address and online name, and save. Select rollback separately if you want it for Online Battle. First run preserves online settings from earlier installations. The launcher shows shared preferences. Per-game files, environment variables and launch arguments can change which settings the game uses.

Discord presence requires a configured numeric application ID in `JSP_DISCORD_APP_ID`. The game skips presence when the ID is missing or invalid, or when `JSP_DISCORD=0`.
